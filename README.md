# База знаний

Веб-приложение для личных заметок и задач. У каждого пользователя свой аккаунт, и он видит только свои данные.

- **Заметки**: дерево страниц любой вложенности, перетаскивание мышкой, визуальный редактор (заголовки, списки, чек-листы, цитаты, код, ссылки), автосохранение.
- **Задачи**: список и канбан-доска, статусы, приоритет, срок, описание, фильтры «На сегодня», «Просроченные» и «Высокий приоритет».
- Поиск по всему (Ctrl+K), светлая и тёмная тема, мобильная версия.
- Аккаунты создаёт администратор, открытой регистрации нет.

Стек: Node.js + Express + встроенный в Node.js SQLite (один файл базы), фронтенд на чистом HTML/CSS/JS без сборки.

## Запуск на своём компьютере

Нужен Node.js версии 22.13 или новее (https://nodejs.org, берите LTS). База данных встроена в сам Node.js, а нужные библиотеки уже лежат в папке `node_modules`, поэтому ничего устанавливать не нужно.

```bash
cd kb-app
npm start
```

Откройте http://localhost:3000. При первом запуске приложение предложит создать аккаунт администратора.

Остальных пользователей администратор добавляет сам: меню внизу слева → «Пользователи».

### Настройки (переменные окружения)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `3000` | Порт сервера |
| `DATA_DIR` | `./data` | Папка с базой `kb.sqlite` |

Если забыли пароль администратора:

```bash
npm run create-admin -- you@example.com "новый-пароль" "Имя"
```

Добавить ~20 примеров заметок (чтобы посмотреть, как выглядит заполненная база):

```bash
npm run demo-notes                       # первому администратору
npm run demo-notes -- you@example.com    # конкретному пользователю
```

Сервер останавливать не нужно — после запуска обновите страницу. Примеры удаляются как обычные заметки («Выбрать» → «Удалить»).

## Как получить обновления

Код хранится на GitHub: https://github.com/kn1xoh/kb-app

1. Откройте GitHub Desktop, выберите репозиторий `kb-app`.
2. Нажмите **Fetch origin**, затем **Pull origin**.
3. Если в описании изменений сказано «нужен перезапуск» — остановите сервер (`Ctrl + C`) и снова выполните `npm start`. Иначе достаточно обновить страницу в браузере (`Ctrl + F5`).

Папки `data` (ваши заметки и аккаунты) и `node_modules` в репозиторий не попадают и при обновлении не меняются.

## Размещение в интернете (VPS)

Подойдёт любой VPS с Ubuntu 22.04/24.04 (1 ГБ RAM хватит). Ниже пример для домена `kb.example.ru`, который уже направлен на IP сервера (A-запись).

**1. Установите Node.js, nginx и pm2**

```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs nginx
sudo npm install -g pm2
```

**2. Загрузите проект и запустите**

```bash
# скопируйте папку kb-app на сервер (scp, git или через SFTP), затем:
cd ~/kb-app
pm2 start npm --name kb -- start
pm2 save
pm2 startup   # выполните команду, которую он напечатает, чтобы приложение стартовало после перезагрузки
```

**3. Настройте nginx**

Создайте файл `/etc/nginx/sites-available/kb`:

```nginx
server {
    server_name kb.example.ru;
    client_max_body_size 5m;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

```bash
sudo ln -s /etc/nginx/sites-available/kb /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

**4. Включите HTTPS (бесплатный сертификат Let's Encrypt)**

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d kb.example.ru
```

**5. Сразу откройте сайт и создайте аккаунт администратора.** Пока его нет, форма первичной настройки доступна любому, кто откроет сайт.

### Обновление

```bash
cd ~/kb-app
# замените файлы новыми (данные в папке data не трогайте)
pm2 restart kb
```

### Резервные копии

Все данные хранятся в одном файле `data/kb.sqlite`. Безопасная копия на лету:

```bash
sqlite3 ~/kb-app/data/kb.sqlite ".backup '/root/backups/kb-$(date +%F).sqlite'"
```

Можно добавить в `crontab -e` для ежедневного запуска (нужен пакет `sqlite3`: `sudo apt install sqlite3`).

### Про бесплатные хостинги (Render, Railway и т. п.)

Приложение хранит базу в файле, поэтому хостингу нужен **постоянный диск**. На тарифах без него база будет стираться при каждом перезапуске. Условия у хостингов меняются, так что проверяйте, есть ли постоянное хранилище (volume/disk), и укажите путь к нему в `DATA_DIR`.

## Структура проекта

```
server.js               API и раздача фронтенда
db.js                   схема базы SQLite
scripts/create-admin.js создание/сброс администратора из консоли
scripts/demo-notes.js   примеры заметок для проверки внешнего вида
public/index.html       страница приложения
public/app.css          стили (цвета и шрифты — переменные в начале файла)
public/app.js           интерфейс
```

Новый раздел добавляется в массив `SECTIONS` в начале `public/app.js`. Для него понадобятся своя функция отрисовки и API в `server.js`.
